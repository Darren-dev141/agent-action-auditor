Privacy and security posture

Your pasted trace is processed in this browser tab. The auditor does not upload it, write it to browser storage, set cookies, or send analytics events. It has no AI endpoint, user accounts, or server-side trace database.

Page loading versus auditing

If hosted, opening the page loads its static files from the host. The host may log ordinary requests, including your IP address. Running an audit sends no network request. Opening the local files avoids a hosting service altogether.

Secrets and reports

Selected secret formats are detected locally. Matching values are masked in the displayed and copied report; the input still contains the original trace until you clear it. Pattern detection is incomplete: absence of a warning does not mean a trace has no secrets.

What Clear does

Clear removes the input and report text from this application's interface and retained report reference. It is not a secure memory wipe. Your browser may restore form text or keep process memory; extensions, developer tools, and your clipboard are outside this tool's control.

No certification

Findings are deterministic, limited trace-based heuristics. They cannot establish authorization, correctness, successful verification, or that an agent is safe to deploy. Review the actual trace and external state.
